# caminhadas

App desenvolvido em Flutter para registrar e acompanhar caminhadas.

* Splash com animação
* Menu lateral
* Tema claro e escuro
* Cadastro de caminhadas
* GPS
* Mapa
* Trajeto
* Cálculo de distância
* Estimativa de tempo e calorias
* Câmera para foto da caminhada

## Tecnologias

* Flutter
* Dart
* Flutter Map
* Geolocator
* OSRM

## Como testar

1. Clone o Repositório

2. Use os comandos
```bash
flutter pub get
flutter run
```
